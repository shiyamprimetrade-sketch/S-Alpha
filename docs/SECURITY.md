# Local prototype security boundary
Only trusted single-user local deployment is supported. No arbitrary source or shell input is accepted by v2. Compiler bounds: 8 parameters, 64 characters per parameter, depth 12, 127 nodes, 64 explicit expected cases, 128 repair attempts maximum. HTTP loopback and token required. UI previews saved bytes only when SHA-256 matches. Task directory symlinks rejected; trusted root and no concurrent hostile filesystem changes assumed. Database and file operations are not atomic; interrupted tasks may require manual reconciliation. Adaptive ordering remains opt-in and is not promoted by default. No independent penetration test or physical Android test. Do not expose server to network.
