# Fusion Android developer preview
From the trusted Alpha checkout on branch fusion-alpha-001, use Termux Python 3.11+ and run `python -m unittest discover -s tests -v`, then `bash scripts/start-fusion-termux.sh`. Open http://127.0.0.1:8767/ in the browser address bar. Use the operation selector and Execute. Generated websites are saved under fusion-workspace/<task-id>/index.html; inventory and repair evidence use fusion.sqlite3. Keep these in private Termux storage. Override the port with --port if occupied. Legacy Alpha server unchanged. This is not a native APK or an Omega-authorized execution boundary. Do not expose the listener to the network. Physical Android and browser JavaScript acceptance pending.
