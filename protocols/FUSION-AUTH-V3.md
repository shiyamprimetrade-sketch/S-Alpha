# Candidate authenticated v3 adapter
Alpha-only proposal: exact v3 envelope, HMAC-SHA256 over sorted compact ASCII JSON (ensure_ascii=true, allow_nan=false), domain alpha-fusion-v3 followed by NUL; result domain alpha-fusion-result-v3 followed by NUL. Key >=32 bytes, trusted local caller allowlist, durable single-use IDs. No key distribution or Omega agreement. Existing UI does not use this adapter. Claim and side effects are not atomic together; interrupted running claims require reconciliation, never automatic retry. This is not SBI/SCC conformance or independent semantic verification.
