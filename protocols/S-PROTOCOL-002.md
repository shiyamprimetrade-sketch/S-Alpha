# Local protocol v2 (draft)
Requests: version=2, id (ASCII alphanumeric, underscore or hyphen, max 64), operation=synthesize|repair|knowledge. Synthesis requires spec with parameters and expression; repair also requires candidate. Optional expected_cases and repair max_attempts. Results include version, id, status and verification evidence or structured error. Artifacts reside under trusted workspace/id/compute.py. Write IDs are single-use. Knowledge is read-only query apart from schema initialization. Adaptive ordering remains opt-in outside this interface. No remote execution or Omega approval.
